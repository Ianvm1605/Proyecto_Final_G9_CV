# Documentación

- [`coverage.md`](coverage.md): relación semana por semana entre el sílabo y las demostraciones de la aplicación.
- [`architecture.md`](architecture.md): límites entre geometría, escena, renderizado y recursos.
- [`interface-overview.svg`](interface-overview.svg): vista general de la interfaz.

## Cómo preparar la demostración

1. Consulta `coverage.md` y selecciona una evidencia por tema.
2. Abre la aplicación y recorre las vistas con el guion recomendado en ese documento.
3. Registra capturas propias y explica qué algoritmo o modelo produce cada resultado.
4. Completa por separado el informe del proyecto y los trabajos colaborativos solicitados por el curso.
